# Changelog

## 0.3.0 - 2026-07-30

- Added live CHP CAD collection for Inland (INCC) and Indio (ICCC).
- Added CHP incident normalization and priority classification.
- Added shared geocode cache for CHP locations.
- Added independent 60-second schedules for Riverside County Fire and CHP.
- Added CHP collector health/status to `/health` and `/emergency`.
- Updated API version to 0.3.0.

## 0.2.0

- Added Riverside County Fire collector.
- Added 25-mile geofence, SQLite incident history, scheduler, and systemd service.
